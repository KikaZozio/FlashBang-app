# Flash Bang

Flash Bang est une application de bureau (Windows, macOS, Linux) pour créer et réviser des flashcards avec un système de répétition espacée, pensée pour les révisions scolaires et universitaires.

## Fonctionnalités

- **Organisation en dossiers > matières > sous-dossiers**, pour classer ses flashcards comme on classe des cours.
- **Répétition espacée personnalisable** : intervalles de révision et comportement en cas d'échec réglables globalement ou pour un dossier/une matière/un sous-dossier précis (avec héritage : le réglage le plus précis l'emporte). Possibilité de **désactiver complètement** la répétition espacée pour un dossier donné (les cartes restent consultables en révision libre, sans jamais revenir automatiquement dans l'agenda).
- **Cartes recto/verso ou recto seul**, avec du texte, des formules mathématiques (rendu KaTeX) et des images.
- **Flashcards « image à légender »** : une image avec des points cliquables à identifier.
- **Agenda/calendrier des révisions** pour visualiser ce qui est prévu, jour par jour.
- **Export/import de partages** (`.fbshare`) : partage un dossier, une matière ou une sélection de cartes avec un ami en un seul fichier autonome (images comprises), sans avoir besoin d'un compte ni d'une connexion entre les deux apps.
- **Mises à jour automatiques** (avec confirmation explicite avant tout téléchargement) : l'app vérifie discrètement si une nouvelle version est disponible et propose de l'installer.
- **Aucune donnée envoyée en ligne** : tout est stocké localement, sur l'ordinateur de l'utilisateur.

## Installation

Télécharge la dernière version depuis la page [Releases](https://github.com/KikaZozio/FlashBang-App/releases) :

- **Windows** : `FlashBang_Windows_<version>.exe` (installateur classique).
- **macOS** : `FlashBang_macOS_<version>.dmg`.
- **Linux** : `FlashBang_Linux_<version>.AppImage`.

Voir [DISTRIBUTION.md](DISTRIBUTION.md) pour construire l'application soi-même depuis les sources, sur les trois plateformes.
